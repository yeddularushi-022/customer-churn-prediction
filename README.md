# Customer Churn Prediction System

A machine learning project that predicts whether a telecom customer is likely to leave a company using customer account and service information.

## Project Overview

Customer churn is an important business problem for telecommunications companies. This project uses machine learning to identify customers who may leave, helping businesses understand customer retention risks.

## Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Machine Learning Models

- Logistic Regression
- Random Forest Classifier

## Model Evaluation

| Metric | Logistic Regression | Random Forest |
|---|---:|---:|
| Accuracy | 80.70% | 77.43% |
| Precision | 65.84% | 56.60% |
| Recall | 56.68% | 64.17% |
| F1-score | 60.92% | 60.15% |
| ROC-AUC | 0.8418 | 0.8275 |

Logistic Regression achieved the highest accuracy, precision, F1-score, and ROC-AUC in the current comparison. Random Forest achieved higher recall for the churn class.

## Features

- Data cleaning and preprocessing
- Categorical feature encoding
- Model training and evaluation
- Customer churn prediction through a Streamlit web application
- Estimated churn probability
- Model performance comparison chart

## How to Run

1. Clone or download this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run the model training script:

   `python main.py`

4. Launch the web application:

   `python -m streamlit run app.py`

## Dataset

Telco Customer Churn dataset: `WA_Fn-UseC_-Telco-Customer-Churn.csv`

## Disclaimer

Predictions are estimates generated by a machine learning model and are not guarantees of future customer behavior.
